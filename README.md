# Langmail MCP for your own Stalwart: email, calendar and contacts

`langmail-mcp` is an open-source [Model Context Protocol](https://modelcontextprotocol.io) server that gives an AI agent the same email, calendar and contacts tools as [Langmail](https://langmail.me)'s hosted MCP server, working against your own [Stalwart](https://stalw.art) mail server over JMAP, CalDAV and CardDAV. It runs on your computer or your server and talks only to your Stalwart; no Langmail service is involved.

Not affiliated with Stalwart Labs.

## Status

Under construction. The server starts and speaks MCP over stdio, but it has no tools yet and nothing is published to npm. Installation and configuration instructions will follow with the first release.
