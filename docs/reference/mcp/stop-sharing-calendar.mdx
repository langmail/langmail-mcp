---
title: "stop_sharing_calendar"
description: "Stop sharing the user's calendar with a person, so the link they were given shows an empty calendar."
keywords: ["stop_sharing_calendar", "unshare calendar", "revoke calendar link", "mcp tool"]
---

Stops a person's share of one calendar, or of every calendar when none is named. The link they were given then shows an empty calendar for good; it cannot be revived, so sharing again with [`share_calendar`](/reference/mcp/share-calendar) gives a new link. Nobody else's share changes. [`list_calendars`](/reference/mcp/list-calendars) shows the current shares.

## Parameters

<ParamField body="with" type="string" required>
  The person, by the name the calendar was shared with, matched ignoring case.
</ParamField>

<ParamField body="calendar" type="string">
  The calendar to stop sharing: its name, matched ignoring case, or its CalDAV URL. Omit it to stop every share with this person.
</ParamField>

## Example

```json Call
{ "with": "Sam" }
```

```text Result
Stopped 1 share(s):
- "Personal" with Sam (busy times only)
Sam's link now shows an empty calendar, for good. No other share changed.
```

## Errors

Every error stops nothing.

- `No share with … ` — nothing matched. The error lists every current share.
- `No calendar named "…"` — the calendar did not match. The error lists every calendar with its URL.
- `Calendar sharing is not set up on this server.`
