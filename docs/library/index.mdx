langmail is an open-source library that parses, cleans and structures raw emails into input for language models. It is published as `langmail` on [crates.io](https://crates.io/crates/langmail), [npm](https://www.npmjs.com/package/langmail) and [PyPI](https://pypi.org/project/langmail/), and it runs in your own code: you don't need a Langmail account to use it.

## What it does

Raw emails are noisy. They contain quoted reply chains, signatures, tracking pixels, malformed HTML, zero-width characters and formatting artifacts of each mail client. Feeding this noise to a language model wastes tokens and makes its output worse.

langmail removes it in two steps. `preprocess()` parses the raw email and strips everything irrelevant. `toLlmContext()` renders the result as a clean, deterministic text block for a prompt.

- **HTML to Markdown:** converts HTML email bodies to clean Markdown, keeping their semantic structure and stripping tracking pixels.
- **Reply detection:** identifies and removes quoted content from Gmail, Outlook, Apple Mail and non-standard clients.
- **Signature stripping:** removes email signatures with heuristic pattern matching, without machine learning or training data.
- **CTA extraction:** finds the primary call to action by its position and structure, and returns it as structured data your model can act on.

## Why Markdown

Markdown keeps the semantic structure of an email while staying far cleaner than raw HTML. A bold subject line, a bullet list of action items or a link with meaningful anchor text carries meaning that plain text loses. Language models have strong priors for Markdown, which helps with summarizing, extracting calls to action and classifying.

## What it is not

langmail does not send or receive emails, and it does not connect to any email provider. It works on raw RFC 5322 messages, so it works with any source: IMAP, the Gmail API, SES, Postmark or a local `.eml` file. For the Gmail API it also takes the API's own message format (see the [quickstart](/library/quickstart)).

## Implementation

The core is written in Rust and published to crates.io as `langmail`. Two bindings wrap it:

- **Node.js:** via napi-rs, published to npm as `langmail`.
- **Python:** via PyO3, published to PyPI as `langmail`.
